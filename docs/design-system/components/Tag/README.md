# Tag

Outlined pill with spaced caps: an eyebrow for offers and the "ONE MORE REASON" marker above a haakje on dark.

**Consumer provides:** a short uppercase label (1–3 words) and the ground.

- `.sl-tag` on light: 1px `line` outline, Archivo 700 11px, `0.2em` tracking, `text-body`. Examples: "GRATIS PROEFLES", "12 WEKEN".
- `.sl-tag.sl-tag-on-dark`: sand-tinted outline, `white` text, 9.5px — sits right above the haakje headline in stories and feed posts.
- Labels, not buttons: not clickable, never orange.
