# HaakjeChip

A small light chip that names one haakje in Anton, used to list the alternatives next to the leading haakje.

**Consumer provides:** the haakje text.

- `.sl-chip`: `surface-card` fill, `ink` Anton 15px uppercase (`chip` style), `radius-chip` (6px), 41px tall, `space-8` gap between chips.
- Not interactive in the toolkit; if you make chips selectable, add the `focus-ring` outline and a visible selected state that doesn't use orange.
