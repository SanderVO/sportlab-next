# CarouselSlide

A 4:5 carousel slide: the instap manifesto as a 6-slide carousel that builds calmly from doubt to one concrete step.

**Consumer provides:** one statement per slide; the last slide carries the CTA.

- `.sl-social.sl-slide` (4:5). Slide 1: wordmark + warm Poppins question on `.sl-dark-steel`. Middle slides: short Poppins lines on `ink`, or an Anton statement on `.sl-dark`. Final slide: haakje + orange CTA (see Story hero).
- One idea per slide; no CTA before the last slide.
