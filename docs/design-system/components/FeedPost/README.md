# FeedPost

Square (1:1) and portrait (4:5) feed posts built from the same blocks: wordmark, kapstok + haakje, orange CTA.

**Consumer provides:** the haakje or offer, an optional eyebrow (e.g. "12-WEKEN CHALLENGE · START SEPTEMBER"), the CTA label, optionally a photo.

- `.sl-social.sl-post` (1:1) or `.sl-slide` (4:5).
- **Systeem:** kapstok in Anton + the haakjes line (`haakjes-line`). No CTA.
- **Challenge:** wordmark + "ONE MORE REASON" tag, eyebrow, haakje in Anton, orange CTA "Doe mee →". The preview uses `group-class-in-action.jpg` as an `.sl-photo` with `.sl-photo-overlay.strong`.
- **Personal training (4:5):** eyebrow tag, warm Poppins heading ("Samen werken aan jouw doelen."), one line of body, CTA "Let’s talk goals".
