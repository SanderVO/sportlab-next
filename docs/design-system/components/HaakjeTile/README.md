# HaakjeTile

A dark tile that shows one haakje: a small "ONE MORE REASON" kicker on top and the haakje in Anton at the bottom.

**Consumer provides:** the haakje text; break long ones over two lines at a word ("TO KEEP / GOING").

- Markup: `.sl-tile` > `.k` (kicker) + `.h` (haakje). 188×150, `radius-card`, `ink` fill, `space-22` padding, `space-16` gap between tiles.
- Kicker: Archivo 700, spaced caps, `text-on-panel-eyebrow`. Haakje: `display-s` (Anton 28px/.93) in `white`.
- Use for overviews of the haakjes and as campaign index cards. Monochrome only, never orange.
