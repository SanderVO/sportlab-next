# Sticker

Monochrome stickers that carry the haakjes: ticket, round seal, label, rep counter and dot pill.

**Consumer provides:** the haakje or label text.

- `.sl-sticker-ticket` — ink ticket with a stitched inner border, rotated −4°: kicker + haakje.
- `.sl-sticker-seal` — round ink seal with dashed inner ring, "ONE MORE REASON" stacked.
- `.sl-sticker-label` (+ `.light`) — "… TO GET STRONG" on `ink` or `sand`, `radius-sticker`.
- `.sl-sticker-rep` — "+1 / REP COUNTER", `radius-badge`. The "+1" is the campaign's one-more idea as a number.
- `.sl-sticker-dot` — warm-white pill with an ink dot and 2px ink border.
- Always monochrome (`ink`, `sand`, `warm-white`, `white`). Orange never appears on stickers.
