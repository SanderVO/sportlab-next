# Lockup

The three One More Reason lockups: the fixed kapstok ("ONE MORE REASON") plus a changing haakje ("… to ___").

**Consumer provides:** the haakje text (one of TO START, TO KEEP GOING, TO GET STRONG, TO STAY FIT, TO STAY HEALTHY, TO KEEP IN SHAPE) and the ground.

- **A — Stacked poster (hoofdvariant).** Gritty, poster-like. Kapstok stacked one word per line in Anton (`display-l`/`display-xl`, line-height .86); the haakje as a fixed line beneath in spaced Archivo caps with "→". On `.sl-dark`.
- **B — Woven patch.** Merch DNA from the "One More" beanie patch: an ink patch with an inner stitched border, slightly rotated. For stickers, hoodies, profile pictures.
- **C — Inline / systeem.** The kapstok stays; only the haakje changes per piece, set in `sand`, with the other haakjes listed underneath in `text-on-panel-eyebrow`.
- Don't: put the kapstok or haakje in orange; don't break the words "ONE MORE REASON" out of order.
